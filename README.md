# Сахар — сайт салона красоты

**Коммерческий проект: сайт используется действующим салоном красоты «Сахар» во Владикавказе.** Он представляет услуги и мастеров салона, показывает примеры работ и предоставляет клиентам доступ к онлайн-записи через YCLIENTS.

**Работающий сайт:** [salon-saxar.ru](https://salon-saxar.ru/)

## Задача проекта

Создать удобную точку знакомства клиента с салоном: от выбора направления и просмотра работ до записи к мастеру. На сайте собраны услуги, команда, контакты, часы работы и карта проезда. Адаптивный интерфейс позволяет пользоваться им с телефона и компьютера.

## Возможности

- **Каталог услуг:** маникюр, педикюр, ресницы, брови, волосы, биозавивка, шугаринг и лазер, перманентный макияж, пирсинг.
- **Портфолио по направлениям:** галереи фотографий с просмотром в увеличенном размере.
- **Карточки мастеров:** фото, специализация, количество отзывов и ссылки на отзывы и запись.
- **Онлайн-запись через YCLIENTS:** встроенная форма на компьютере и переход в сервис на мобильных устройствах.
- **Контакты и навигация:** звонок, ссылки на мессенджеры, Яндекс Карты и маршрут до салона.
- **Аналитика:** подключены Яндекс Метрика и Google Analytics.

## Как устроен сайт

Основная часть — статические HTML, CSS, JavaScript и изображения. Браузер загружает `gallery.json` и `masters.json`, затем формирует галереи и карточки мастеров. Сборка через Node.js и база данных для сайта не требуются.

Python-скрипты подготавливают контент: один собирает фотографии в JSON, второй получает сведения о мастерах через браузер Playwright. Данные обновляются при ручном запуске скриптов; сайт читает сохранённые файлы. Выбор времени и оформление записи происходят в YCLIENTS.

В интерфейсе предусмотрены мобильное меню, отложенная загрузка фотографий, анимация появления блоков и управление модальными окнами с клавиатуры.

## Локальный запуск

Используйте Python 3.10+. Для просмотра сайта достаточно встроенного HTTP-сервера:

```bash
git clone https://github.com/daytimeserg0/sahar.git
cd sahar
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Запускайте сайт через HTTP-сервер: загрузка JSON через `fetch` при открытии `index.html` как локального файла может блокироваться браузером.

### Через Flask

В репозитории также есть `app.py`. Для запуска в Windows / PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install flask
.\.venv\Scripts\python.exe app.py
```

Сайт будет доступен по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000). На Linux/macOS вместо `.\.venv\Scripts\python.exe` используйте `.venv/bin/python`. Flask запускается в режиме отладки для локальной разработки.

## Обновление контента

### Фотографии и галереи

Разместите фотографии в соответствующих папках:

| Папка | Содержимое |
| --- | --- |
| `images/hero/` | Главное фото сайта |
| `images/previews/<category>/` | Обложка направления |
| `images/works/<category>/` | Фотографии работ |

Категории: `manic`, `pedic`, `lashes`, `brows`, `hair`, `biowave`, `laser`, `permanent`, `pirsing`. Поддерживаются также существующие папки вида `images/<category>/`.

После изменения фотографий выполните из корня проекта:

```bash
python generate_gallery.py
```

Скрипт пересоздаст `gallery.json`. Для главного фото и обложки выбирается первый файл по имени. Поддерживаемые форматы: JPG, JPEG, PNG, WebP, GIF и AVIF. Дополнительные пояснения — в [README-images.txt](README-images.txt).

### Карточки мастеров

Скрипт `parse_yclients_masters.py` получает имена, специализации, фотографии и количество отзывов с публичной страницы YCLIENTS, формирует ссылки на запись и сохраняет результат в `masters.json`.

В созданном виртуальном окружении выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe parse_yclients_masters.py
```

Локальные фотографии в `images/masters/` можно назвать по ID или имени мастера: при совпадении они имеют приоритет над фотографиями YCLIENTS. Обновление требует доступа к интернету и зависит от разметки страницы сервиса. `generate_gallery.py` не обновляет файл `masters.json`.

## Структура проекта

```text
index.html                 Страница сайта и JavaScript
style.css                  Стили и адаптивная вёрстка
images/                    Фотографии салона и работ
gallery.json               Данные главного фото, обложек и галерей
masters.json               Карточки мастеров
generate_gallery.py        Генерация данных галереи
parse_yclients_masters.py   Обновление данных из YCLIENTS
app.py                     Локальный сервер Flask
CNAME                      Пользовательский домен salon-saxar.ru
```

## Размещение

Для публикации достаточно статического хостинга с `index.html`, `style.css`, папкой `images/` и актуальными JSON-файлами. Python-инструменты запускаются отдельно при подготовке контента. Подключённый домен указан в `CNAME`.
